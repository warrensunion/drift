# Drift Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Drift — a scroll story plus a 3D ocean globe where dropped plastic fragments drift on real currents, moved by a model trained on real drifter tracks, shown with uncertainty.

**Architecture:** Python preprocesses open data into compact `DRFT` binary tiles and trains a small MLP exported to ONNX. The browser site is Vite + vanilla ES modules: a DOM scroll story paints first; three.js (WebGPURenderer, WebGL2 fallback) and the model load lazily; a Web Worker runs the ensemble with onnxruntime-web and streams snapshots the GPU interpolates.

**Tech Stack:** Vite 8, three 0.186 (`three/webgpu`, TSL), onnxruntime-web 1.30, Playwright 1.64, sharp; Python 3.12 (uv) with torch (CPU), xarray, netCDF4, onnx, onnxruntime.

**Spec:** `docs/spec.md`

## Global Constraints

- No framework; any new dependency is logged in `DECISIONS.md`.
- three.js and the model are lazy-loaded; the intro paints without them.
- `prefers-reduced-motion`: cross-fades instead of motion. No WebGL: static fallback that logs `[drift] static fallback: <reason>`.
- Works from 390 px wide, no horizontal scroll; touch drops on phones.
- 60 fps target with 20,000 particles on a laptop.
- Every track view is labelled "Simulation with uncertainty — not a forecast".
- Every dataset has a DATA.md line (name, source URL, licence, date fetched, processing) and appears in the site credits.
- No invented numbers: fragmentation, windage, sinking, beaching and gyre values come from `docs/science.md` (cited).
- Art: original only; makemepulse is a timing/technique reference, never traced.

## Review Focus

1. Click/tap on land, or off the globe — expect a short "Drop it in the water" message and no particles (Task 8 test `drop on land is refused`).
2. Longitude wrap at the antimeridian and sampling near ±80° lat (Task 3 tests `sample wraps across 180°` and `sample beyond lat range is land`).
3. On a phone, a vertical drag on the globe must scroll/rotate, only a tap drops (Task 8: tap = pointerdown→pointerup < 8 px and < 300 ms).
4. Scrubbing past the time the worker has computed so far — the scrubber shows the computed extent and clamps (Task 7 test `snapshot index clamps to computed`).
5. More than 20,000 members — the oldest drop retires, nothing throws (Task 7 test `budget retires oldest drop`).

- [ ] Tests: JS features equal Python features on the fixture rows within 1e-6; onnxruntime-web (node, wasm) outputs equal PyTorch within 1e-4.
